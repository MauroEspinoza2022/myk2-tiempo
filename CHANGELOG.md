# Versiones

## 1.2.0
- PDF ejecutivo con indicadores, gráficos vectoriales, consolidado y trazabilidad de movimientos.
- Excel con seis hojas, gráficos nativos editables, fórmulas, filtros y estilos profesionales.
- Saldo de apertura y cierre de períodos, incluyendo movimientos anteriores.
- Validación de fórmulas, gráficos y conciliación de informes.

## 1.1.0
- Aplicación instalable con icono propio, nombre myk2 Tiempo, manifest y service worker.
- Instalación Android/escritorio e instrucciones para iPhone/iPad.
- Dashboard administrativo de usuarios, actividad y tráfico, con directorio y búsqueda.
- Estadísticas protegidas por permisos de administrador; medición por identificadores anónimos.
- Migración Supabase 002 para directorio de correos y estadísticas.

## 1.0.0
- Registro de horas en Lima con corrección manual, comentarios y cruces de medianoche.
- Horario semanal configurable, descansos solicitados/aprobados/gozados/cancelados.
- Panel de saldo, historial, informes PDF y Excel, respaldos JSON.
- Interfaz responsive y marca myk2.
- Cuatro temas de lectura con degradados suaves y selector persistente.
- Publicación automática con pruebas mediante GitHub Actions.
- Integración Supabase con registro, acceso, recuperación de contraseña, RLS y administrador; requiere configurar el proyecto externo.
